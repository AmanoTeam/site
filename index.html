Two founders, one group chat,
eight years of shipping.

Amano was founded in January 2018 by Alisson and Eduardo. Our first project, @EduuRobot, was meant to be an admin bot for a single Telegram group. Within days it became clear that everyone needed one — so we made it public, and it never stopped growing.

Since then the team has kept shipping: Telegram bots, Python and Rust libraries, Android mods, and an entire family of GCC cross-compilers. Most of it open source. All of it built in the open.

  • Open by default 84 public repositories. Code first, marketing later.
  • Small tools, sharp edges Dependency-free packages that do one thing well.
  • No trackers, no nonsense We build Unalix and JustDeleteMe for a reason.
